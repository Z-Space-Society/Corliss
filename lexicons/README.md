# Lexicons — prototype copy

**These do not belong here.** `CLAUDE.md` says the membership lexicons and the
Lua that serves them belong to
[scn-member-registry](https://github.com/Z-Space-Society/scn-member-registry);
Corliss consumes lexicons and owns none.

They are on this branch because the scene-notes prototype needs a schema in the
tree to build and test a web client against. Before anything merges to `main`,
either:

- move them to `scn-member-registry` and import or vendor the schema from there,
  or
- record a deliberate decision that Corliss hosts its own read/write lexicons,
  and update `CLAUDE.md` to say so.

Design notes live in the SCN vault: `Code/Scene Note Lexicon.md` and
`Code/Corliss Spaces SCN Notes Evolution.md`.
