The Team

A small working group in Vancouver. Between them: the hardware and the operations, the models the cluster actually serves, and the agentic interface members reach them through. Two advisors round it out.

{% if avatars.jacob %} {% endif %}

Jacob Sayles

cascadia.design

Jacob is the Technical Steward, the one who builds the cluster and keeps it running: the inference machines and the Proxmox host they answer to, Corliss (this app), and zai-ops, the Proxmox/Ansible IaC that stands the whole thing up from bare metal.

Stewardship is designed into the project rather than bolted onto it. Shared resources need someone at the helm, especially as systems get more complex. Making that a defined role rather than a volunteer accident is also what lets another community run one of these without inventing the operations from scratch.

{% if avatars.scott %} {% endif %}

Scott Hadfield

hadsie.com

Scott is the man behind the models. He decides what actually runs on the nodes: which open weights are worth serving, at what quantisation and context, and which machine each one belongs on. That is the part of this system a member meets first and judges it by.

He also wrote the ATProto lexicons behind the membership record, and the first admin console for working it.

{% if avatars.pouria %} {% endif %}

Pouria Delfan

pouriade.com

Pouria is a designer and software engineer. He is the lead on Gel.Chat, an agentic user chat integrated with atproto permissioned data. Gel is the default agentic interface for SCN, as well as being adopted by the atproto community.
