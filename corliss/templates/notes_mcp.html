Connect Obsidian

{% if sync_url %}
{{ sync_url }}
  1. In Obsidian, create a new, empty vault. On iPhone, leave Store in iCloud off.
  2. In Settings → Community plugins, turn on community plugins, then Browse, search for SCN Sync, and Install and Enable it.
  3. Paste the address above when it asks for the sync address.
  4. Sign in with your handle.
  5. Pick one of your vaults from the list.

Do the same on each device. Notes sync as you add them.
